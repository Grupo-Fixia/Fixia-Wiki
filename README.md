# fixia-wiki

Documentación técnica de arquitectura, herramientas, procesos y políticas
del equipo de Desarrollo y DevOps de **Fixia** — plataforma que conecta
clientes con proveedores de servicios (plomería, pintura, electricidad,
etc.) cerca de su ubicación geográfica.

> Este repositorio es la wiki. No contiene código de los microservicios.

## Empezar acá

👉 [00-inicio/README.md](./00-inicio/README.md) — qué es esta wiki, cómo
está organizada y cómo leer una página de decisión.
